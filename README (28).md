# ⚔️ Морской Бой 10×10 (PvP & PvE)

Автономная веб-игра **«Морской Бой»**, созданная на чистом HTML, Tailwind CSS и JavaScript.

## 🚀 Особенности игры
- **Размер поля:** Классическое поле **10×10 клеток**.
- **Флот (по 1 кораблю каждого размера):**
  - 4-палубный (1 шт.)
  - 3-палубный (1 шт.)
  - 2-палубный (1 шт.)
  - 1-палубный (1 шт.)
- **Синхронизация готовности (PvP):**
  - Когда один из игроков нажимает «Готов к бою», игра переходит в режим ожидания.
  - Бой начинается одновременно для обоих игроков только после того, как оба подтвердят готовность.
- **Индикатор попаданий и потоплений:**
  - `💧 Капля воды` — промах.
  - `🔥 Огонь` — ранена отдельная палуба корабля.
  - `✕ Крестик` — корабль полностью уничтожен (потоплен).
- **Экран конца игры:**
  - При победе или поражении всплывает модальное окно с результатами и кнопкой возврата в меню.
- **Игровые режимы:**
  - 🤖 **Играть против Бота** (умный PvE).
  - 🏠 **Создать комнату (PvP)** через PeerJS.
  - 🔑 **Войти в комнату (PvP)** по ID друга.

## 🛠️ Запуск проекта
1. Сохраните файлы `index.html` и `README.md` в одну папку на компьютере.
2. Дважды кликните на `index.html`, чтобы открыть игру в любом современном браузере.
